# ZeeSpare identity

Open `brand-guide.html` for the visual guide and `ZeeSpare-brand-guide.pdf` for sharing. Master SVGs are resolution-independent, with outlined wordmarks so no font installation is required. PNGs have transparent backgrounds. The app uses the same native SVG mark with accessible live text.

- Machine-readable colors and rules: `brand-tokens.json`

Write ZeeSpare, never Zeespare or ZEE SPARE. Use the full name on first reference. Lead with concrete planning decisions and honest evidence; avoid claims of guaranteed availability or autonomous execution. Brand promise: clarity across demand, inventory and replenishment.

The precision Z connects two stock positions with one deliberate diagonal. Its detached signal terminal represents the next part in the network. Keep its geometry, spacing and proportions. Never mirror, stretch, rotate, outline, add shadows, use lime for small text on paper, or place the logo over busy imagery.

Public branding changes do not rename existing API key prefixes, x-zeespare-* protocol fields, database roles, engine modules, workspace package names or the GitHub repository. Those identifiers remain stable to protect existing integrations. Historical reports retain their original names.
